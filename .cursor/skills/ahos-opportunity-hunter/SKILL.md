# AHOS opportunity hunter

Mission: surface candidates early. This skill does not decide.

Pipeline the hunter must respect:

IDENTITY → EVIDENCE → SECURITY → LIQUIDITY/EXITABILITY → SCORE → RISK →
CONFIDENCE → optional AI downgrade → CANONICAL DECISION

Hunter output: candidate list + evidence pointers + unknowns.
Positive eligibility requires canonical identity and security PASS.

Do not bypass Lane A ranker semantics for the frozen experiment.
Do not let a high opportunity score override critical security risk.
Confidence stays independent from opportunity.
