# Browser screenshots

Run `npm run dev` in one terminal, then run `npm run screenshots` in another. The Playwright script captures calm, breach, and map mode at 1600×900 and checks the renderer creation counter after 50 prop updates.

**Current workspace status: UNVERIFIED.** This environment has no Chromium/Chrome executable, so no real browser screenshots are included here. The screenshot script is included for reproducible capture on a machine with Playwright Chromium installed; do not treat generated mockups as browser evidence.
