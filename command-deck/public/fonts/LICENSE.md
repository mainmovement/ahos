# Bundled webfonts

All fonts in this directory are bundled locally (no remote loading).

## Vazirmatn (Persian + Latin)

- Files: `vazirmatn-*-*.woff2`
- Source: @fontsource/vazirmatn (npm), which packages the Vazirmatn project
  (https://github.com/rastikerdar/vazirmatn)
- License: SIL Open Font License 1.1

## Inter (Latin, variable)

- Files: `inter-latin-wght-normal.woff2`
- Source: @fontsource-variable/inter (npm), which packages the Inter project
  (https://rsms.me/inter/)
- License: SIL Open Font License 1.1
