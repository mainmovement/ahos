# Human model assets

The rigged character models under `public/models/humans/` are unmodified
copies of the demo assets shipped in the three.js repository
(https://github.com/mrdoob/three.js — MIT license):

- `Soldier.glb` — rigged male soldier; Idle / Walk / Run clips.
- `Michelle.glb` — rigged female character.
- `kira.glb` — rigged female character.
- `rpm.glb` — Ready Player Me sample avatar (used by the three.js
  animation-retargeting examples).

They are used here purely as decorative, simulated command-room staff.
No real person is depicted; every figure is a stylized 3D demo asset.

All other imagery in `public/textures/` remains NASA public-domain
imagery via the three-globe examples (see `public/textures/LICENSE.txt`).

Live data shown on room screens (when reachable) comes from public,
key-less endpoints: Binance / OKX / CoinGecko (crypto), gold-api.com
(spot gold), Yahoo Finance via the allorigins CORS mirror (indices and
crude oil), Open-Meteo (Dezful weather), BBC Persian RSS (headlines).
Holdings shown next to live prices are a DEMO constant — the UI says so.
