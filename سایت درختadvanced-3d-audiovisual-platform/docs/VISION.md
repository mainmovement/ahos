# AHOS Master Vision

Artificial Hybrid Opportunity Scoring System.

AHOS is not a trading bot. It is a searching, questioning, risk-gating intelligence.

## Doctrine

- Evidence before decision.
- Rumor ≠ fact.
- High opportunity + critical security risk = REJECT.
- UNKNOWN / INSUFFICIENT EVIDENCE / CONFLICTED / UNVERIFIED are legal states.
- Skip is a result.
- No change without a record.
- $0 initial budget. Local first. Provider abstraction.
- Single user in phase 1.
- Beauty must not sacrifice auditability.

## Loop

Discover → Analyze → Decide → Paper trade → Monitor → Result → Post-mortem → Learn → Update → Retest → Improve.

## Council

Ten specialist teams. No team decides alone. The red team asks what if everyone else is wrong.
