# AHOS — Artificial Hybrid Opportunity Scoring System

Cinematic intelligence chamber for emerging-token discovery.

## Stack

- Next.js App Router
- PostgreSQL + Drizzle ORM
- WebGL (three.js) void scene
- Web Audio UI + ambient drone
- Local council engine ($0 budget)

## Chambers

Command, Discovery, Market, On-chain, Social, News, Security, Council, Chat, Paper, Alerts, Telegram, Learning, GitHub, Reports, System, Settings.

## Run

```bash
npx drizzle-kit push
npm run dev
```

Doctrine lives in `docs/VISION.md`.
