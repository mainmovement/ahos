# AHOS — MASTER AUTONOMOUS EVOLUTION & COMPLETION DIRECTIVE (W43)

**Project:** AHOS — Artificial Hybrid Opportunity Scoring System  
**Mission:** Event-Driven Evolutionary Market Intelligence System  
**Primary mode:** Single-user / Local Laptop  
**Architecture principle:** Observation First → Evidence → Analysis → Scoring → Decision Support → Learning → Governed Evolution  
**Safety principle:** UNKNOWN > fabricated certainty  
**Current truth:** Green tests ≠ project completion

---

## فرمان اصلی

AHOS باید به‌صورت یک سیستم یکپارچه، قابل‌اندازه‌گیری، قابل‌توضیح، قابل‌ممیزی، مقاوم در برابر خطا، خودمشاهده‌گر، خودتشخیص‌گر و دارای مسیر حکمرانی‌شده برای خودبهبود تکامل پیدا کند.

**بدون توقف جلو برو.** برای هر تغییر معمول مهندسی از کاربر اجازه نگیر. اما مرزهای Governance و Safety را نشکن.

هر چیزی که نیازمند secret واقعی، API key پولی، token تلگرام، دسترسی خارج از permission، اجرای واقعی روی laptop، یا دادهٔ ناموجود است:

```text
BLOCKED / REQUIRES USER ACTION / REQUIRES EXTERNAL SERVICE / GOVERNANCE REQUIRED
```

ثبت شود و بخش‌های مستقل ادامه یابد.

## اصل بنیادین صداقت داده

2. Chat intentها را به subsystem مناسب هدایت کند.

5. ranking چندعاملی باشد.
6. security gate مستقل باشد.
7. social intelligence به‌عنوان evidence عمل کند، نه hype generator.
8. expert council uncertainty را حفظ کند.
9. watchlist/portfolio monitoring وجود داشته باشد.
10. hindsight واقعی وجود داشته باشد.
11. documentation drift کنترل شود.
12. secrets و zero-money invariants حفظ شوند.
13. تمام external limitations صادقانه گزارش شوند.
