# AHOS CANONICAL — MISSION
**AHOS = Artificial Hybrid Opportunity Scoring System** — Early Crypto Opportunity Intelligence &
Decision Support. NOT a trading bot. NOT a pump oracle.

## Purpose (permanent)
Continuously discover newly-emerging tokens, verify them across market/on-chain/security/whale/social/
narrative/tokenomics/catalyst evidence, rank them explainably, monitor user paper-positions, and answer:
"which early token has statistically meaningful probability of a predefined significant move — why,
with what evidence, what invalidates it, and what to watch next" — in natural Persian via Telegram.

## Absolute laws (never negotiable)
1. NO CLAIM WITHOUT DATA · UNKNOWN stays UNKNOWN · no fabricated fields/metrics/tests/provider claims.
2. Security veto precedes opportunity; UNKNOWN security ⇒ recommendation ≤ WATCH.
3. Rank-first until the research gate promotes a validated model; "NO OPPORTUNITY" is a successful output.
4. $0/month ceiling; free-first providers with fallbacks; Iran-resilience; no paid API without explicit user authorization.
5. PAPER-only execution; live trading requires separately-documented gates + human authorization (currently CLOSED).
6. A–E maturity letters mandatory (A Designed · B Implemented · C Tested · D Verified · E Production Ready).
7. Rejected hypotheses/failed tests/provider failures = immutable evidence (never hidden, never deleted).
