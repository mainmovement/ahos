## Static dead-code limitations

A Python import/reference grep cannot prove a public library function is dead. CLI execution, dynamic imports, n8n shell commands, and operator use are legitimate inbound edges. For that reason:

- no file is labeled safe-to-delete solely because no Python import was found;
- test-only implementations are labeled `ORPHAN` or `EXPERIMENTAL`, not automatically `DEAD_CODE`;
- historical patches/snapshots are preservation evidence;
- every removal still requires the manifest process defined in the duplicate register.
