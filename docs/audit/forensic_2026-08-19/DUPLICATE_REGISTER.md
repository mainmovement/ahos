## Deletion law

Before deleting or collapsing any item above:

1. identify every inbound import, CLI, config, schema/table, report, and test;
2. document semantic differences and unique behavior;
3. select a replacement based on correctness, integration, tests, architecture fit, Windows support, and dependencies;
4. port required behavior and add regression tests;
5. run replay/current-store compatibility checks;
6. create a deletion manifest with original hash and preserved history path;
7. obtain explicit human approval.
