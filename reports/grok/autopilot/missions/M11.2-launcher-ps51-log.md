# M11.2: launcher/ahos.ps1 hidden path in Windows PowerShell 5.1 (log + no double-run)

Context: box review of ba4d455 (read-only; Windows-only, could not run). Snapshot 238b090 + box branch grok-box-debug.

## Problem (two parts)
1. `launcher/ahos.ps1` hidden path: `& $Python @PyArgs 2>&1 | Tee-Object -FilePath $LogPath -Encoding utf8 -Append | Out-Null`.
   `Tee-Object -Encoding` exists only from PowerShell 7.2 (CHANGELOG 7.2, #12135). The .lnk target is
   `C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe` (5.1), so parameter binding throws, the `catch`
   re-runs `& $Python @PyArgs` without logging, and `logs\launcher\launcher.log` is NEVER written on the owner's machine.
2. Latent: under `$ErrorActionPreference = 'Stop'`, PS 5.1 turns every redirected native stderr line (`2>&1`) into
   a terminating NativeCommandError. Once (1) is fixed naively, the first Python warning on stderr aborts the
   pipeline mid-run and the `catch` runs the SAME action again (double start / double stop / double restart).

## Required change (files: launcher/ahos.ps1 only, plus tests)
- Hidden path: set `$ErrorActionPreference = 'Continue'` locally around the native call (or call python via
  `Start-Process -NoNewWindow -Wait -RedirectStandardOutput/-RedirectStandardError` to two temp files, then append
  both to launcher.log as UTF-8 with `[IO.File]::AppendAllText(path, text, [Text.UTF8Encoding]::new($false))`).
- Never re-run the action from a `catch`. If logging fails, log nothing and keep the single run's exit code.
- `$rc` must be python's exit code in both paths.
- Stay ASCII-safe for PS 5.1 parsing (existing test_phase18 parse checks) and keep `-Console` semantics.

## Acceptance
- tests/test_phase18_launchers.py: new static tests: no `Tee-Object` with `-Encoding`; no `& $Python` inside a `catch`;
  hidden path writes via `[IO.File]::AppendAllText` or `Out-File -Encoding utf8`.
- Owner-run (Windows) receipt: double-click AHOS.lnk -> `logs\launcher\launcher.log` exists, is UTF-8, contains the
  Persian progress lines once; `reports\launcher\status_*.json` shows ONE start action.
- Existing 3 launcher suites stay green (box: 144 passed / 4 skipped on Linux).
