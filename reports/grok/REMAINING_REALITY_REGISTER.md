# AHOS Remaining Reality Register

Remaining Capability Graph per owner directive part1 §76–§80. Nodes are
capabilities; edges are dependencies, proof requirements, and governance gates.
**Docs-only evidence caps a capability at `PLANNED`/`DESIGN`. Self-tests cap it
at `TESTED`.** Independent verification against real data is what separates
`TESTED` from `VERIFIED`, and a real soak is what separates `VERIFIED` from
`OPERATIONAL`.

Compiled 2026-10-03 from code, tests, and live artifacts only — no readiness
prose was accepted as evidence. Live-artifact counts were re-queried for this
register and are quoted verbatim.

Status date 2026-10-03 · Companion files: `reports/m9/BASELINE.md` (part A),
`reports/m9/IMPORT_SIDE_EFFECTS.md` (part B), `reports/FAILURE_MEMORY.md`.

## Ladder (§76)

`VISION < DESIGN < PROPOSED < PLANNED < PARTIAL < IMPLEMENTED < TESTED <
VERIFIED < ACCEPTED < OPERATIONAL < PRODUCTION-CAPABLE`, plus `BLOCKED`,
`UNKNOWN`, `CONTRADICTED`.

## Evidence tiers used in this register

| tier | meaning |
|---|---|
| **tests** | passes on synthetic fixtures in `tests/`. Supports `TESTED` at most. |
| **runtime** | a live artifact produced by the system itself (`data/*.sqlite` row counts, `reports/*.json` receipts). Supports `VERIFIED`. |
| **soak** | continuous operation over time with an externally observable feed. Required for `OPERATIONAL`. |
| **docs** | markdown only. Caps at `PLANNED`/`DESIGN`. |

## The graph

Legend: **State** — ladder position. **Evidence** — the strongest artifact that
exists. **Depends on** — upstream capabilities (dependency edges). **Proof** —
what evidence would move it one rung up. **Gov** — human-gated? (Yes = do not
implement, list it.)

## Critical path (§79–§80)

The chain that blocks everything below it:

```
pre-soak entry (G2/G3/G10 = NOT_VERIFIED)        <-- standing blocker
   └─> paper trading closed-loop (0/30 exits)    <-- the economics gate
         └─> outcome labels (508 of 22,285)      <-- statistical power
               └─> predictive calibration        <-- DESCRIPTIVE_OK today
                     └─> decision authority live (0 runtime decisions)
                           └─> soak / OPERATIONAL
```

The single highest-leverage node is **§7: close paper positions**. It unblocks
§8 (labels → ledger), §6 (predictive calibration), and §12 (the authority has
nothing to decide on). It requires no human gate and no new capability — only
wiring the existing `run_full_cycle` into the daemon and running it long enough.
